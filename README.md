Påminnelser för mig själv: 

För att starta programmet: 

Se till att docker desktop är startat. 
Starta din databas med: docker start postgres-container
Kontrollera att den är igång: docker ps / docker ps -a
Starta servern: node main.mjs


Stäng av servern: CTRL + C
Stäng av databasen: docker stop postgres-container
